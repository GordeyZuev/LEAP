## 📅 May 2026

### 2026-05-20: v0.9.7.0 — релиз

Релиз фокусируется на **удобстве работы** оператора и **надёжности пайплайна** для нестандартных видеоформатов.

#### 📋 References API
- Новый эндпоинт `/api/v1/references` отдаёт фронтенду статические справочники: языки транскрибации, гранулярности тем, уровни качества yt-dlp, поддерживаемые платформы, таймзоны. Данные кешируются на 24 часа — нет лишних запросов при каждом открытии формы.

#### 📋 Копирование сущностей
- Шаблоны, пресеты и задания автоматизации можно продублировать одним запросом (`POST …/copy`). Копия получает имя «Copy of …» с автоматической нумерацией при коллизиях.

#### 🎬 Исправление WebM / VP8 pipeline
- Видео с кодеками VP8/VP9 + Vorbis/Opus больше не вызывают ошибку «несовместимый мюксер»: перед тримом pipeline определяет кодеки через ffprobe и выбирает подходящий контейнер (`.mp4` / `.webm` / `.mkv`).

#### 🔧 Устойчивость тримминга
- Перед запуском FFmpeg проверяется наличие видео- и аудиопотоков; потоки маппируются явно только если существуют; ошибка ffprobe не роняет весь шаг обработки.

### 2026-05-11: v0.9.6.6 — релиз

Этот релиз выравнивает **одни и те же бизнес-правила** на всём пути видео: от выбора файла на Яндекс.Диске и загрузки через API до проверки после скачивания. Оператору и интегратору проще понять, *какие файлы платформа вообще принимает* и *как они лежат на диске*.

#### 📥 Один whitelist форматов
- Допустимые расширения видео заданы **централизованно** (кортежи `STORAGE_DEFAULT_*` в `config.settings`) и попадают во все сценарии: пикер Яндекс.Диска, загрузка записи через API, загрузка из Zoom / yt-dlp / публичных ссылок.
- Переменные **`STORAGE_SUPPORTED_VIDEO_FORMATS` / `STORAGE_SUPPORTED_IMAGE_FORMATS` в `.env` больше не меняют поведение** — список меняется только выпуском версии. Это убирает «тихие» расхождения между окружениями и тем, что реально поддержано кодом (в т.ч. sniff контейнера).

#### 🗂️ Файлы записей и диагностика
- Запись сохраняется как **`source.<расширение>`**, согласованное с именем/типом источника (Яндекс, Zoom `video_file_type`, имя при локальной загрузке). Раньше по умолчанию часто был «везде `.mp4`», что усложняло разбор проблем.
- После сохранения остаётся **проверка целостности**: не HTML-страница вместо видео, совпадение **расширения и реального контейнера** (например WebM/MKV vs MP4), базовый контроль размера.

- Настройки **`YTDLP_COOKIES_FILE`** (Netscape-файл) или **`YTDLP_COOKIES_FROM_BROWSER`** — cookies подставляются в **yt-dlp** при скачивании и метаданных (см. `video_download_module/platforms/ytdlp/opts.py`)

- В конфиге записи / транскрипции задаётся **`language: en`** — язык протягивается по этапам: **ASR**, извлечение тем и метаданных, **LLM** (описания, вопросы), **субтитры** и дальнейшая обработка (см. `api/tasks/processing.py`, `master.json`)
- Единая локаль по цепочке даёт согласованный текст на английском от транскрипта до публикации

### 2026-02-12: v0.9.5 — Multi-Source Video Ingestion & Yandex Disk

**Главное нововведение:** платформа теперь поддерживает добавление видео из любых источников — не только Zoom. Видео можно добавить по ссылке, импортировать плейлист целиком или загрузить с Яндекс Диска.

#### 📥 Добавление видео по ссылке

- Одно видео по URL — система сама определит платформу (YouTube, VK, Rutube и др.)
- Импорт плейлиста — все видео добавляются отдельными записями, повторный импорт не создаёт дубликатов
- Опция запуска сразу после добавления — без дополнительного шага
- Форматы: видео (mp4) или только аудио для транскрибации
- Выбор качества: от 480p до лучшего

#### 💿 Интеграция с Яндекс Диском

- Добавление по публичной ссылке — без предварительного подключения аккаунта
- Синхронизация папки — периодический импорт новых видео из выбранной папки
- Выгрузка на Диск — структура папок по шаблону (курс, дата), автосоздание
- Токен доступа хранится зашифрованным

#### 🏗️ Единый процесс для всех источников

- Один и тот же цикл: загрузка → обработка → выгрузка — для Zoom, YouTube, VK, Rutube, Яндекс Диска
- Система сама определяет тип источника по метаданным

#### 📖 Документация

- [YT_DLP_GUIDE.md](guides/YT_DLP_GUIDE.md) — как добавлять видео по ссылке (YouTube, VK, Rutube)
- [YANDEX_DISK_GUIDE.md](guides/YANDEX_DISK_GUIDE.md) — как подключить и выгружать на Яндекс Диск
